# Grouprise UNRELEASED

Release date: *NOT YET*

## Search

The incremental group search (reachable via the group search widget in the top navigation bar)
failed to work since the introduction of the optional geo feature.


## Notifications

It could happen, that email notifications were sent only to a few subscribers of a group, if one of
the recipients was rejected by the mail server.
All messages for subsequent recipients were discarded.
Now failures are ignored.
