# Grouprise 5.5.1

Release date: *2024-04-27*

## Administration

### Debian release compatibility

*grouprise* and its dependencies are now (again compatible with Debian Bullseye.
Accidentally v5.5.0 only worked with Debian Bookworm.
This new release now works with Bullseye and Bookworm.

### Service Restart

Previously the *grouprise* service gave up after a certain number of failed startup attempts
(e.g. in case of a missing database server).
Now the service will try to restart forever.


## Django

Fix warnings regarding early database access during *app setup*.

*grouprise* is now compatible with Django v4 or later.


## Data Processing

The explanation text regarding the data processing related to the use of the contact form is now
unified.
Previously copies of the same text were used with slight variations in different contexts.
